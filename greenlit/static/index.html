Connection & release criteria

RAG responses should include actual retrieved passages. Agent responses should include tool calls and their results. Missing evidence leads to REVIEW.

Quick Gemini run: 6 questions and 1 trial. The included math chatbot also consumes Gemini quota. Calls are spaced to reduce bursts, so runs take longer and measured target latency includes any server queue. Memory and repeatability need a larger run.

Any score decline from a comparable previous run blocks release.

For memory tests, configure an API template that accepts the full messages history. Otherwise memory/clarification will be unverified.

By default, GreenLit reuses questions from the latest comparable run for this API. Any score decrease gives NO-GO. You can also select an approved baseline.
